# Network_Information_Security_TUES_12_grade
The coursework on the subject "Network and Information security" in TUES in 12 grade.

## Company Profile: SkyPort Aviation Services OOD

### Sector: Aviation Services / Ground Handling
##### Locations: Sofia (HQ), Plovdiv Airport, Varna Airport

## Description

SkyPort Aviation Services OOD provides critical ground handling operations across three major Bulgarian airports: Sofia, Plovdiv, and Varna. Central to their business is the Operations System (OPS), which coordinates flights in real time.
To ensure high availability and data integrity, data security policies strictly regulate access controls and automated night backups.
