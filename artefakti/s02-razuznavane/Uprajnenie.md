# Анализ на уязвимостите и мотивация (CVE-2021-41773)

## 1. Уязвимости
### 1.1. Path Traversal
- **Описание**: Софтуерна грешка при **нормализацията** на URL път, позволяваща на външен атакуващ да заобиколи ограниченията за достъп до нерегламентирани пътища на сървъра.
- **Въздействие**: Пълно компрометиране на системни файлове, пароли и др.

### 1.2. Remote Code Execution през CGI
- **Описание**: Използване на Common Gateway Interface (CGI) протокола манипулация на системата, чрез изпълними системни файлове.
- **Въздействие**: Възможност за изпълнение на всякакви системни изпълними файлове с привилегии на потребител www-data (имащ обикновено root).

## 2. Мотивация
1. Използва се софтуерен бъг и следователно атаката не може да се блокира от мрежова инфраструктура, нито от защитни стени на сървъра.
2. Доказателство на важността от използване на най-съвременни версии, защото дори малка уязвимост може по този начин да срине големи системи.
